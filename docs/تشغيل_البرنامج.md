# تشغيل البرنامج على حاسبتك

> نسخة `.exe` جاهزة **لم تُبنَ بعد** — بناؤها بـ PyInstaller مؤجَّل حتى تكتمل
> الحسابات. حتى ذلك الحين يُشغَّل البرنامج من مصدره بالخطوات التالية. تُنفَّذ
> **مرّة واحدة** ثم يصير التشغيل نقرة واحدة.

---

## أولاً — تنصيب بايثون (مرّة واحدة)

نزّل **Python 3.11** أو أحدث من <https://www.python.org/downloads/>

**مهم:** في أول شاشة من المنصّب، ضع علامة على
**Add Python to PATH** قبل الضغط على Install. بدونها لن يتعرّف ويندوز على الأمر.

للتأكد، افتح **موجّه الأوامر** (اكتب `cmd` في قائمة ابدأ) واكتب:

```
python --version
```

يجب أن يظهر رقم النسخة. إن ظهر خطأ، أعِد التنصيب مع تفعيل الخيار أعلاه.

---

## ثانياً — إحضار البرنامج (مرّة واحدة)

### إن كان Git منصَّباً

```
git clone https://github.com/Yasser1981/work_order.git
cd work_order
git checkout claude/modest-albattani-756v94
```

### إن لم يكن Git منصَّباً

افتح المستودع في المتصفّح، وبدّل الفرع إلى
`claude/modest-albattani-756v94`، ثم **Code ← Download ZIP**، وفكّ الضغط.

---

## ثالثاً — تنصيب المكتبات (مرّة واحدة)

من داخل مجلد المشروع:

```
pip install -r requirements.txt
```

---

## رابعاً — التشغيل

```
python app.py
```

**لتسهيلها:** أنشئ ملفاً نصّياً في مجلد المشروع باسم `تشغيل.bat` محتواه سطران:

```
@echo off
python app.py
```

بعدها يكفي النقر المزدوج عليه.

## خامساً — التأكد من سلامة النسخة

```

```

يجب أن تنتهي بـ **242 passed**. أي رقم أقل، أو أي `failed`، يعني خللاً — أرسل لي
النص كما هو.

## كيف تجرّب البرنامج — سيناريو كامل

1. **لسان «المقاطع»** ← اختر النوع من الأعلى واضغط **إضافة مقطع**.
2. أدخل **طول المسار**، واختر **مفردة/مزدوجة**.
3. اقرأ سطر **المقترح** تحت المسافات، ثم اضغط **اعتماد القيم المقترحة ↓**.
   الأعداد **استرشادية**: عدّلها كما تشاء، فهي مُدخَلات لا نتائج (ق-١٠).
4. أضف مقاطع أخرى — ضغط واطئ، تجهيزات — وسمِّ كل مقطع باسمه الحقيقي.
5. راقب **جدول المواد** و**أجور العمل** على اليسار: يتحدّثان مع كل ضغطة.
6. **اضغط على أي مادة في الجدول** ← يظهر تحتها **تفصيل مصدر كميتها**: من أي مقطع
   جاءت وبأي معادلة. هذا ما يجعل الرقم قابلاً للتدقيق.
7. **لسان «أمر العمل»** ← املأ الترويسة والكوادر والآليات.
8. اختر القالب من القائمة أسفل اليمين، ثم **طباعة (PDF)**.

### ما يستحق تجربته خصيصاً

| جرّب | ما يجب أن يحدث |
|---|---|
| مقطعان بنفس النوع، أحدهما مفرد والآخر مزدوج | كمية السلك تختلف بينهما، وتُجمع في سطر واحد بتفصيلين |
| مقطع ضغط واطئ بالأسلاك وآخر بالقابلو المعلق | المادتان تظهران معاً — الشبكة المختلطة |
| تغيير المسافة بين الأعمدة من 25 إلى 40 | المقترح يتغيّر فوراً |
| إدخال مستهلكين | يظهر تحذير أصفر: «كونكتر ربط مشتركين» بلا سعر |
| مشروع فارغ ثم الضغط على طباعة | يُرفض صراحةً بدل إخراج نموذج فارغ |
| ثلاثة مقاطع 11 ك.ف | بند «نصب عمود مشبك 11م» يبقى **سطراً واحداً** بالمجموع |

### التحذير الأصفر أسفل الشاشة

يعني: **مواد أو بنود لم تُحتسب في المجموع لأن سعرها غير محدَّد بعد**. ليس خطأً —
بل تنبيه مقصود كي لا تمرّ المادة بصفر صامت. قائمتها في `docs/قائمة_التذكير.md`.

## أين تُحفظ الأسعار

| الوضع | مكان ملف الأسعار |
|---|---|
| التشغيل من المصدر (الآن) | `data/catalog_2026-08.json` في مجلد المشروع |
| بعد بناء الـ`.exe` | مجلد `data` **بجانب الملف التنفيذي** |
| إن كان مجلد البرنامج محمياً من الكتابة | `<مجلد المستخدم>/أوامر_العمل/data` |

عند أول تشغيل للـ`.exe` تُنسخ نسخة المصنع تلقائياً إلى مجلد قابل للتعديل.
و**تحديث البرنامج لا يمحو أسعارك** — النسخة الموجودة لا تُستبدل أبداً (ق-٢٨).

النسخ مؤرَّخة: `catalog_2026-08.json`، وحين تُضاف `catalog_2027-01.json` يستخدم
البرنامج الأحدث تلقائياً، وتبقى القديمة لأوامر العمل التي بُنيت عليها (ق-٠).
