# دليل بناء البرنامج على ويندوز — خطوة بخطوة

يُنفَّذ **مرّة واحدة** لتهيئة الحاسبة. وبعدها يصير كل بناء لاحق نقرتين على
`بناء.bat`.

> **لماذا على ويندوز؟** لأن PyInstaller **لا يبني لنظام آخر**. الملف التنفيذي
> لويندوز يجب أن يُبنى على ويندوز — لا خيار «بناء متقاطع» فيه.

---

## أولاً — التهيئة (مرّة واحدة)

### ١. بايثون

نزّله من **python.org/downloads** — نسخة **3.11 أو أحدث**، 64-bit.

> ⚠️ **في أول شاشة من التنصيب ضع علامة على «Add python.exe to PATH»**
> قبل الضغط على Install. هذه أكثر خطوة يُنسى وضعها، ومن دونها لا يعمل أمر
> `python` في الطرفية.

للتحقّق: افتح **موجّه الأوامر** (اضغط ⊞Win ثم اكتب `cmd`) واكتب:

```
python --version
```

فإن ظهر رقم النسخة فالتهيئة سليمة. وإن ظهر «not recognized» فأعد التنصيب مع
وضع العلامة، أو أعد تشغيل الحاسبة.

### ٢. المستودع

**إن كان Git مثبَّتاً:**

```
git clone https://github.com/Yasser1981/work_order.git
cd work_order
```

**وإن لم يكن:** افتح صفحة المستودع على GitHub ← زرّ **Code** الأخضر ←
**Download ZIP**، ثم فُكّ الضغط في مجلد تعرفه (مثلاً `D:\work_order`).

> **الفرق:** مع Git تسحب التحديثات بأمر `git pull`. وبلا Git تُنزّل ZIP جديداً
> كل مرّة. **وفي الحالتين احتفظ بمجلد `data` عند المستخدم** — لا تنسخه فوق
> أسعاره.

### ٣. المكتبات

في موجّه الأوامر، داخل مجلد المشروع:

```
pip install PyQt6 openpyxl pytest pyinstaller
```

يستغرق دقائق (PyQt6 كبير).

## ثانياً — البناء

### الطريقة السهلة

**انقر `بناء.bat` نقرتين.**

### أو من موجّه الأوامر

```
python بناء_الملف_التنفيذي.py
```

### ماذا يحدث

| الخطوة | ما يجري | إن فشلت |
|---|---|---|
| ١ | **تشغيل الاختبارات** | يتوقّف — لا يُبنى ملف تنفيذي من شيفرة ساقطة |
| ٢ | **البناء بـ PyInstaller** | يتوقّف ويطبع السبب |
| ٣ | **التحقّق من المخرَج** | يطبع المسار والحجم |

**المخرَج:** `dist\أوامر_العمل.exe` — نحو **55 إلى 60 ميغابايت**، وهذا طبيعي:
الملف يحمل بايثون ومكتبة Qt كلها بداخله، فلا يحتاج المستخدم تنصيب شيء.

---

## ثالثاً — التسليم إلى حاسبة المستخدم

**انسخ الملف التنفيذي وحده.** لا تنصيب، ولا سجلّ ويندوز، ولا صلاحيات مدير.

عند أول تشغيل يُنشئ البرنامج بجانبه مجلد `data`:

```
📁 أي مجلد يختاره المستخدم
├── أوامر_العمل.exe
└── 📁 data
    └── catalog_2026-08.json      ← الأسعار، تُحرَّر هنا
```

### تحذير SmartScreen في أول تشغيل

سيقول ويندوز **«Windows protected your PC»** لأن الملف غير موقَّع رقمياً.
اضغط **More info ← Run anyway**. مرّة واحدة فقط لكل حاسبة.

> هذا لا يعني وجود خلل — التوقيع الرقمي يحتاج شهادة سنوية مدفوعة. أخبرني إن
> أردت بحث الأمر لاحقاً.

### ولو وُضع في مجلد لا يُكتَب فيه

كـ`C:\Program Files`: يتحوّل مجلد البيانات تلقائياً إلى
`C:\Users\<الاسم>\أوامر_العمل\data`. والاختبار فعليّ لا اعتماداً على الصلاحيات
المعلنة — ويندوز يعلن صلاحيات لا يحترمها دائماً.

## رابعاً — التحديث لاحقاً

```
git pull                          (أو نزّل ZIP جديداً)
python بناء_الملف_التنفيذي.py
```

ثم انسخ `أوامر_العمل.exe` الجديد **فوق القديم**.

> ### ⚠️ القاعدة الذهبية
> **استبدل الـ`.exe` وحده. لا تلمس مجلد `data`.**
>
> أسعارك المحرَّرة تعيش هناك. والبرنامج يحميك أصلاً: نسخة المصنع تُنسخ **فقط
> إن لم يكن الملف موجوداً**، ولا تستبدل ملفاً قائماً أبداً (ق-٢٨، ق-٠).
> **وهذا مُختبَر على المخرَج المبنيّ** لا على النيّة.

**وتعديل سعر لا يحتاج بناءً أصلاً** — حرّر ملف JSON في `data` مباشرة.

## المشكلات الشائعة

| العَرَض | السبب | الحلّ |
|---|---|---|
| `'python' is not recognized` | لم تُوضع علامة PATH | أعد تنصيب بايثون مع العلامة، أو أعد التشغيل |
| `'pip' is not recognized` | نفسه | جرّب `python -m pip install ...` |
| `No module named PyQt6` | المكتبات لم تُثبَّت، أو تعدّد نسخ بايثون | `python -m pip install PyQt6` |
| حروف مشوّهة في الطرفية | ترميز ويندوز غير UTF-8 | `بناء.bat` يضبطه تلقائياً؛ ومن الطرفية اكتب `chcp 65001` أولاً |
| مضادّ الفيروسات يحجب الملف | سلوك معتاد مع ملفات PyInstaller غير الموقَّعة | استثنِ المجلد، أو أضف الملف إلى القائمة البيضاء |
| الاختبارات تسقط فلا يُبنى | خلل حقيقي في الشيفرة | أرسل لي نصّ الخطأ — **لا تتجاوز الاختبارات** |

## ملاحظة على الخطّ العربي

يختار البرنامج **وقت التشغيل** أول خطّ عربي متاح على الحاسبة، بهذا الترتيب:

**Simplified Arabic** ← **Traditional Arabic** ← **Tahoma** ← **Arial**
← خطوط لينكس ← `serif`

فعلى ويندوز مع أوفيس يُختار «Simplified Arabic» وهو الخطّ الرسمي المعتاد،
وبلا أوفيس يُختار **Tahoma** وهو مشحون مع كل نسخة ويندوز وعربيّته ممتازة
(ق-٥١).

# الطريق الأسهل — تنزيله جاهزاً بلا بناء (ق-٥٢)

**لا تحتاج بايثون ولا أدوات ولا أي تهيئة.** GitHub يبني الملف التنفيذي لويندوز
على خوادمه عند كل تعديل، وأنت تنزّله جاهزاً.

## الخطوات

1. افتح المستودع: **github.com/Yasser1981/work_order**
2. اضغط تبويب **Actions** في الأعلى
3. اختر آخر تشغيل ناجح — علامة **✔ خضراء** بجانبه
4. انزل إلى أسفل الصفحة، قسم **Artifacts**
5. اضغط **أوامر_العمل-ويندوز** فيُنزَّل ملف ZIP
6. فُكّ الضغط ← بداخله **`أوامر_العمل.exe`**

## ملاحظات

- **يجب أن تكون داخلاً بحسابك في GitHub** لتنزيل الـArtifacts.
- **علامة ❌ حمراء تعني أن الاختبارات سقطت** — ولا يُبنى ملف حينها. وهذا مقصود:
  لا يصلك ملف تنفيذي من شيفرة ساقطة.
- الملفات تبقى **90 يوماً** ثم تُحذف تلقائياً. وكل دفعة جديدة تُنتج ملفاً جديداً.
- البناء يستغرق نحو **5 إلى 10 دقائق** بعد كل تعديل.

## متى تبني بنفسك إذن؟

- إن أردت تجربة تعديل **قبل** دفعه
- إن كنت بلا إنترنت
- إن أردت البناء لحظياً بلا انتظار

وإلا فالتنزيل من Actions أسرع وأضمن.
